# Pomodoro Timer
A Pomodoro technique timer. Single-page application built with plain HTML, CSS, and JavaScript, no external dependencies (except the Quicksand font).

## Features
- Work / short break cycles with a long break after a configurable number of cycles.

- Configurable duration for work, short break, and long break.

- Configurable number of short breaks before a long break.

- Progress indicator dots under the timer.

- Pause, resume, and skip the current phase.

- End-of-phase sound via Web Audio API (no audio files).

- Volume control and a sound test button.

- Responsive layout for mobile devices.

## Usage
1. Clone the repository or download index.html.

2. Open the file in a browser.

3. Press > to start the timer.

4. The "Настроить" (Settings) button in the bottom-right corner opens the settings panel.

No server or build step is required.

## Structure
The project consists of a single index.html file containing markup, styles, and the script.
